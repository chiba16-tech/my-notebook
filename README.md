# こもれびノート 🌿

iPad miniで使う、日本語の手書きノート・仕事管理Webアプリの試作版です。フレームワーク不要のHTML / CSS / JavaScriptで動きます。

## できること

- Apple Pencilの筆圧に対応した手書き、色・太さの変更、線単位の消しゴム、直前の描画を戻す
- 方眼・横罫・無地の切り替え、複数ノートの作成・タイトル変更・削除
- 月間・週間カレンダー、日付・時刻つきの予定追加・削除
- 期限つきタスク、チェック表、完了数の表示
- ブラウザ内への自動保存、JSONバックアップの書き出し・復元

## パソコン・クラウドで起動

Node.js 22以上を推奨します（開発時は24で確認）。アプリ実行には外部パッケージは不要です。

```sh
cd /workspace/my-notebook # 手元のPCではクローンしたフォルダへ移動
npm start
```

ブラウザで `http://localhost:3000` を開きます。`PORT=4000 npm start` でポートを変更できます。クラウドのlocalhostはiPadから直接開けません。iPadでは以下のGitHub Pagesを使ってください。

## iPad miniのSafariで使う（GitHub Pages）

1. GitHubで `chiba16-tech/my-notebook` を開き、**Settings → Pages** へ進みます。
2. **Build and deployment → Source** を **Deploy from a branch** にします。
3. Branchに **main**、フォルダに **/ (root)** を選んで **Save** します。
4. 公開完了後、Pages画面に表示されたURLをiPad miniのSafariで開きます。通常は `https://chiba16-tech.github.io/my-notebook/` です。公開できる条件はGitHubのプラン・リポジトリ公開設定によります。
5. Safariの共有ボタンから **ホーム画面に追加** すると、次回から開きやすくなります。

GitHub Pagesの有効化・公開完了は別の操作です。このリポジトリを保存しただけではサイトは公開されません。HTML/CSS/JSだけを配信するため、GitHub Pages上でNode.jsを動かす必要はありません。

### 最初の使い方

- **ノート**：タイトルと用紙を選び、Apple Pencilで紙の上に書きます。指はスクロールに使えます。指で描く場合は「指でも書く」をオンにします。
- **消しゴム**：選択中に線をなぞると、その線全体を削除します。「戻す」は最後の描画線を削除します。削除した線を復活させる機能はありません。
- **スケジュール**：月間・週間を選び、日付をタップして予定を追加します。時刻なしは終日です。下の一覧は選択日の予定です。
- **仕事・チェック表**：項目と任意の期限を追加し、終わったらチェックします。
- **バックアップ**：画面下の「バックアップを書き出す」でJSONを「ファイル」に保存します。「復元する」で選び直せます。復元は現在の全データを置き換えます。

## 保存について

データは閲覧中の端末・ブラウザ・サイトURLごとのlocalStorageに保存します。GitHubやサーバーには送信しません。アカウント・端末間同期・通知・オフライン起動保証はありません。プライベートブラウズは避け、通常のSafariで使ってください。Safariのサイトデータ削除、保存容量不足、端末故障などで失われる可能性があるため、定期的なバックアップをおすすめします。ホーム画面版とSafariや、異なるURL間で同じ保存領域になることは保証しません。
